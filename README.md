# everything for macOS

> 开发预览：图形界面、真实 SMB 共享盘、定时刷新及 Intel 设备上的运行尚未完成验证。

一个 macOS 文件名搜索工具，把个人文件夹和已连接的 SMB 共享盘放在一起搜索。搜索使用保存在本机的文件名与属性索引，不读取文档正文；与 Windows 版 Everything 无隶属关系。

## 使用

1. 将应用放入“应用程序”文件夹并打开。首次运行会建立索引；个人文件夹中资源库和常见缓存会跳过。
2. 如需搜索共享盘，在 Finder 中连接 SMB 服务器，然后点击“刷新索引”。程序自动发现当前已挂载的 SMB 共享盘；使用者无需填写路径。
3. 输入文件名关键词。多个词需要同时出现在文件名中。使用来源和文件类型菜单筛选，点击列标题排序。
4. 按空格预览，双击打开，Command+C 复制文件；在 Finder 中粘贴。右键可拷贝、在 Finder 中定位或拷贝路径，支持多选和拖放。
5. 菜单栏放大镜可打开搜索、设置快捷键和自动刷新。默认快捷键为 Control+Option+空格。默认每日 12:30 刷新，并在登录时启动；可在“自动刷新设置”中调整。

刷新依据系统本地时区；Mac 关机或休眠、共享盘断开时不能保证按时扫描。离线共享盘保留上次索引，但文件打开和复制需要恢复连接。重新连接后刷新索引。目录读取失败会在状态中提示。索引是快照，文件更改要等下次刷新才会反映。

文档优先使用 WPS；没有 WPS 时使用系统默认应用。macOS 对受保护目录或网络卷可能要求授权；未获得权限的目录无法完整索引。首次扫描可能持续较长时间并产生网络流量。

## 安装与隐私

发布包如未经过 Apple 开发者签名和公证，首次打开可能被 macOS 阻止；请在系统设置的隐私与安全性中按系统提示选择打开。请自行核验下载来源。

索引、扫描状态和错误记录保存在 `~/Library/Application Support/EverythingMac/`；它们可能包含本机和共享盘文件名、路径、大小及修改时间。程序无需上传这些数据。登录与定时任务保存在 `~/Library/LaunchAgents/`，可在应用的自动刷新设置中关闭。

## 构建

需要 macOS 12 或更高版本与 Xcode 命令行工具。在仓库根目录运行：

```sh
./scripts/build.sh
```

生成 `build/everything.app`，包含 Apple Silicon 与 Intel 两种架构，使用临时签名，未公证。构建不需要第三方包管理器。运行测试：

```sh
python3 tests/test_indexer.py
python3 tests/test_search.py
```

测试使用临时目录模拟共享盘，不访问个人文件。索引只覆盖文件名与属性，不提供文件正文搜索。
